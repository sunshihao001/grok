# alpha-economic-experiment

**Status:** draft skill *template*. Phase 1: **Paper-Only**. This is not proof of installation or review in the Grok UI. Role owners: B04.

## When to use

Pre-register and challenge Solana meme predictive hypotheses, net executable costs, exit risk and multiple-strategy comparisons.

## Inputs and approved access

Frozen hypothesis/population/cutoff, B02/B03 time-safe evidence, baseline, fees, latency, position sizes and route/exit data.

## Source-aware steps

1. Define strategy family without restricting to FCZ: wallet/capital lead, post-exit secondary phase, liquidity absorption, trend continuation, social diffusion or negative-risk filter. Register observational feature definitions before inspecting future outcomes.
2. Prevent FCZ hindsight: define early zone and POC/AVWAP using only pre-decision history; if zone depends on later rally, classify as descriptive research, not entry feature.
3. Lock target window, baseline, data coverage and cluster/time split. Include unalerted launches and negative cases where appropriate. Compare incremental prediction rather than raw 2x probability.
4. Model entry at a realistically attainable price after alert, network and data latency; include route, slippage, price impact, priority/tip and failed fills.
5. Model exit, size capacity and catastrophic downside. Use observed sell depth or explicit cost-model assumptions and report sensitivity, never ATH/MFE as executable realized gains.
6. Require B05 independent challenge and B06 untouched OOS/real-case replay. Keep externally reported returns separate from locally reproduced or actual traded results.

## Output contract

Preregistered strategy candidate, null baseline, prediction + cost assumptions, explicit potential falsifiers, simulated net return distributions and unknowns.

Emit a versioned Bot handoff conforming to `knowledge/bot-handoff.schema.json` and the role-specific `knowledge/bot-knowledge-profiles.v1.json` (never silently assert externally reported material was locally reproduced). Request a peer review where the F Gate requires it. Handoff files are research artifacts, not authorization to trade or release new Monitor rules.

## Stop and approval policy

No as-of features / executable exit / baseline / fully costed model => hypothesis-only; never report positive net edge.

All tasks are read-only/paper-only. No private keys, signing, swap, order placement or on-chain broadcast. Independent research cannot grant itself Monitor rule release. Grok private skills must be added/enabled by the user after testing; they are not automatically registered by this GitHub directory.
