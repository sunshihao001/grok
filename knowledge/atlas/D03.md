# D03｜AMM、流动性、成交与价格形成

> **原有知识与来源入口**：knowledge/domain/L1-L2-chain-market.md；https://github.com/raydium-io/raydium-docs-v1/blob/main/products/cpmm/math.mdx。

## 专家的中心问题

不问‘价格涨了多少’就下结论，而是问一笔新增订单经过什么路由、吞吐多少可用储备、对其他持仓者的报价造成了什么变化。

## 从基础对象到专业机制的八个知识单元

### D03-01｜池模型和价格函数

**这个知识真正解决什么：** CPMM、CLMM、launchpad 曲线和多池聚合器使用不同状态变量；CPMM 无费概念模型 k=x*y，交易数量影响平均成交价与边际价。

**必须拆穿的误解：** 不能用同一个‘流动性 USD’代表所有价格冲击函数。

### D03-02｜真实储备与虚拟储备

**这个知识真正解决什么：** 实际 vault 金额、曲线有效储备、已计提但未提出费用与美元估值区分；报价需使用程序实际参与曲线计算的净储备。

**必须拆穿的误解：** 链上 vault 的 raw balance 不必然等于可用于曲线的储备。

### D03-03｜交易费、创建者费与 LP 收益

**这个知识真正解决什么：** trade fee、可选 creator fee、protocol/fund/LP 份额在不同 CPMM 配置下分别计算，方向和记账时点会影响净报价。

**必须拆穿的误解：** 创建者持仓为 0 并不必然无费用收入，但未启用 fee 也不得假设有收入。

### D03-04｜价格冲击、滑点与仓位容量

**这个知识真正解决什么：** 给定 SOL 输入与预期 token 输出、目标卖出 token 数量和报价资产输出，是不同方向的量；规模越大平均价通常越偏离边际价。

**必须拆穿的误解：** K 线最高价不是可一次性清仓的报价。

### D03-05｜买卖成交量与风险敞口

**这个知识真正解决什么：** 反复套利/库存调整可以产生很高成交量，却未形成持久的独立风险敞口；同时净买和净卖指标可能因方向/池子定义改变。

**必须拆穿的误解：** buy_volume-sell_volume 不自动等于新增独立资本。

### D03-06｜LP 增减与价格下跌来源

**这个知识真正解决什么：** 撤出 LP、单边 swap、美元计价 SOL 价格变化、池迁移能形成相似的表面 liquidity decline，需分类底层事件。

**必须拆穿的误解：** 美元流动性下降不能只凭一个指标证明 LP 被开发者抽走。

### D03-07｜MEV、排序、Jito 与价格传播

**这个知识真正解决什么：** 交易先后、优先费、Jito bundle 和套利会改变执行结果；领先买入可抬高后来者的成本，并可能影响领先者未来出售的可得报价。

**必须拆穿的误解：** 同 slot 不等于同 bundle，更不证明同一经济受益人。

### D03-08｜深度的动态性和尾部行情

**这个知识真正解决什么：** 当前小额 quote 不能保证未来大额退出；同步卖盘、流动性抽离、路由不可用和失败交易会使尾部损失非线性扩大。

**必须拆穿的误解：** 某时刻‘买入流动性很高’不能代表危机时 sell-side capacity。

## 本领域应该向其他领域提出什么问题

本领域不是孤立百科。研究者须把当前机制向上追溯原始事实、向下追问经济影响：数据口径/交易解码 → D03 内部机制 → 钱包/市场角色或策略 → 跟随者可见性与可卖性。对尚未能由观察支持的市场结论保留竞争解释，不设置主观概率。
