## 每一单元到底应怎样研究到深处

以 **D05-01「资金边的真实经济职能」** 为例：

1. **最小对象**：一条 SOL/token 的转账、其签名/指令、资产和时间。
2. **真实机制**：可能是交易本金、费用代付、托管归集、LP 投资、费用收入；每种具有不同的资产与权利账本。
3. **专家认识**：E-L3-02 要问谁承担风险、谁有执行权、谁最终获益，而不是只数钱包之间连了多少边。
4. **交叉机制**：E-L3-03 看可卖库存、E-L2-02 看池储备与价格冲击、E-L3-05 看同步共因。
5. **未知或竞争解释**：同一转账图也可能由公共服务商解释；真实受益合同不上链时必须保留不可识别性。
6. **应用边界**：这形成专业经济组织知识，**尚不能**直接发出跟单 BUY 或宣布同控身份。

该粒度适用于其余 95 个单元。**单元目录不是研究完成线**：后续 GPT 针对某单元继续深入，要写出真实协议机制、经济利益冲突、变更情形、专业分歧和仍未解决的知识问题，而不是为每个单元再复制固定段落。

## 现实缺口与下一步的专业研究顺序

**第一层要深挖的专业物理基础**：D01/D02/D03/D10。尤其包括账户/ProgramID 真实状态变化、各发行协议版本/曲线、不同池与可卖深度、GMGN→OKX/RPC 的语义和实时时钟。

**第二层是核心市场经济关系**：D04/D05/D06/D07。重视资金组织为何这样运行、不同交易者是否真正分散承担风险、库存/LP/手续费收入如何改变动机、群体时序的反身性。

**第三层是策略和可兑现性**：D08/D09/D11。探索不复制原钱包首笔买卖的机会、可预测信息与价格吸收、两侧报价和尾部退出；再做独立经济检验。

**贯穿所有阶段**：L0 来源、D12 GPT→GitHub→Grok 流程、人工冻结发布。**理论先行与市场实证是不同阶段**；没有真实案例不妨碍 GPT 深化知识，但市场收益必须后续实测。
