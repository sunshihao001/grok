# 12 领域分类与逐层过滤审查（V1.1）
## 审查结果

保留 D01–D12 作为知识本体的稳定索引；**不把 12 个领域当成依次通过的过滤器**。专业知识是按问题选择的一张图，证据的可采信程度是另一套独立且适配研究目标的门槛。

### 经审查发现的问题

1. 旧图谱把 D08（策略）绑定到 D03/D05/D06/D07，意味着问“纯粹价格策略”也要求钱包控制论证；D11（实验）绑定到 D09（执行经济学），让纯测量审计也被误判需要交易经济学。现把 `depends_on` 缩减到**真正的无条件学科前置**，其他联系迁移到 `related_domains`。
2. D06“筹码与控制”容易把 Top10 地址集中度和同一实际经济控制人混用；定义可观测供应与经济聚类是独立对象。
3. D07 旧范围缺少叙事、KOL/社交传播、市场注意力、跨币关系和市场状态。这些可能影响发现阶段，但不能自动证明盈利。
4. D10（数据质量）和 D11（反证/统计）原先排在后面的领域序列中，现在定义为**贯穿所有经验命题的横切检查**。
5. 关键词直匹配仍无法识别别称、长句、反义否定、时间切分；只可做预路由；没有匹配应主动发现新来源，不应宣布不存在知识或优势。
6. D01/D07 的 `declared_research_gap` 指的是未绑定主知识卡，**不是**这两门学科没有资料，也不是市场上不存在相应机制。

### 更新后的责任划分

| 主题 | 领域 | 不得越界推断 |
|---|---|---|
| 链上事实与生命周期 | D01、D02 | 交易存在不等于操作者身份 |
| 价格与流动性 | D03 | 历史价格峰值不等于可成交价格 |
| 钱包、资金、持仓与市场环境 | D04–D07 | 聚类、持仓集中、叙事热度不等于盈利预测 |
| 机制假设 | D08 | 可解释不等于能预测 |
| 交易经济学与风险 | D09 | 命中率不等于净收益 |
| 数据与实证审查（贯穿） | D10、D11 | 引用论文/回测不等于本项目独立复验 |
| AI 工作流与发布治理（贯穿） | D12 | Agent 自己提规则，不等于获准执行 |

## 与领域分类**分离**的七道 F0–F6 过滤关卡

| Gate | 研究问题 | 缺失时的处理 |
|---|---|---|
| F0 目标 | 解释、预测、经济验证还是监控发布？总体、时点、预测窗？ | 只定义问题，不产生市场结论 |
| F1 适用知识 | 哪些文档及领域真正适用？ | 新来源发现，不能直接丢弃稀有模式 |
| F2 可审计事实 | 是否有正确时点、单位、原始交易和覆盖率？ | INSUFFICIENT，不把缺失当作假信号 |
| F3 机制反证 | 观察、归因、替代机制是否区分？ | 可以提出假设，不断言实控或因果 |
| F4 预测增量 | 是否优于基准，且在全新时段/群组有效？ | 结构信号不升格为 Alpha |
| F5 经济兑现 | 延迟、成交、滑点、手续费、退出后仍有正净期望？ | 不声称盈利，必要时否决策略 |
| F6 人工发布 | 是否有独立审查、冻结规则、监测漂移与回滚？ | 仅纸面研究，不修改生产门控 |

**Gates 不是用来过滤掉全部“暂时无证明的研究课题”**：首次发现的现象可保留 F0–F3 的研究身份；F4/F5 未通过之前不得宣称正净期望，F6 未满足前不可自动进入 Monitor。知识发现与交易准入的门槛必须有不同出口。

### 必须按研究目标分支，而不是强行全部通过

- 问“同源资金是否为 CEX HUB”：研究到 F3 即可给结构/反证结论；并非所有此类问题都要算交易净收益。
- 问“这个同步资金现象能提前预测币价吗”：继续做 F4，并报告对照样本与时间切分；即使 F3 有结构证据也不能跳过 F4。
- 问“能否跟单赚钱”：必须到 F5。这里可以先用明显不可成交/卖不出的事实快速排除执行候选，再决定是否投入昂贵的预测实验；**门槛要求不会禁止成本优先的资源优化顺序**。
- 问“升级监控 Bot”：经过 F6 人工审阅及发布/回滚；本项目仍仅允许研究和只读监控。

### 机器层承诺与限制

`ontology.v1.json` 提供硬先决条件与可选上下文，`filter-policy.v1.json` 定义过滤门槛。路由和过滤计划只组织研究，不自主核实链上事实；`NOT_EVALUATED` 不能变成 `PASS_WITH_EVIDENCE`，除非未来具备可审计的独立证据验证器及人类复核。当前 PR 的代码只会构造计划与执行原有 observed/available-at 时间检查，绝不声称完成了 F3–F6。
