# 知识研究的主导认知｜全局保持完整，围绕核心机制纵深突破

> **地位**：本文件规定**怎么研究与推进知识**，不是新本体、证据门槛、交易策略或第 22 位专家。知识分类仍以 `ontology.v1.json` 的 L0–L7 / D01–D12 为准；152 个单元仍以 `whole-domain-atlas.v1.json` 为目录；21 位专家仍来自 `knowledge/experts/registry.v1.json`；市场证据的准入仍按 `filter-policy.v1.json` 的 F0–F6 分目标处理。
>
> **当前阶段**：GPT 深层理论与专业机制研究；不以真实单币案例/回测作为开展研究的强制条件，也不把逻辑推导冒充市场实测、收益发现或生产规则。Grok 仍是未来使用经审查知识与程序的运行端。
>
> **核心原则**：**全局知识图保持完整；每轮选择一个有市场意义的核心矛盾；由最合适的主专家把机制钻深，必要时跨域让相关专家挑战；新知识回填既有最小单元并更新跨域关系；再根据新的认知改变下一轮选题。**

## 1｜先修正三种低效的研究方式

**逐个读完152个单元**：适合查漏，却会人为割裂资金、流动性、库存、时序与跟单；每个小主题似乎讲完了，整体经济机制仍是空的。

**一次研究整个 D01–D12**：方便铺目录，却容易反复列“现象、风险、需要验证”，没有深入任何一条利益、约束和价格传导链。

**让21个专家轮流发表意见**：看似多视角，实则若没有独特问题和反对机制，只是在增加文字长度。专家人数不代表研究深度。

**正确分工**：

- `whole-domain-atlas.v1.json`：**覆盖检查表**，证明未漏掉需要研究的知识问题；不决定研究先后。
- `whole-domain-expert-handbook.md`：**全局地图**，告诉我们哪些专业知识依赖、相交、互相限制。
- **一条核心市场机制**：当轮**真正的研究对象**，从经济问题向下追问，再向上推演。
- `registry.v1.json` 中一位**主专家**：负责提出专家独有的问题、解释因果、主动修正自己的模型。
- 1–3 位必要的**挑战专家**：只在能引入新的约束、不同收益函数或反向因果时加入；不是每轮固定人数或必须投票。
- `source-admission.v1.json` / D10 / D11：约束所引技术事实、来源和经验主张；不能将未证假设升级成真实身份或 Alpha。

## 2｜研究的两个方向：不断往返，而不是线性背知识

### 向下挖：市场问题 → 参与者/权利 → 资产账本 → 程序与价格机制

例如：“为什么一组钱包集中买入，后来的跟单者却拿不到相同收益？”

主专家不能只回答“因为滑点”。应依次拆：

- 钱包买入的资产来自哪个池/程序？在此之前池中可交换的两侧储备是什么？
- 该钱包真正付出的是什么报价资产、多少费用？它的交易改变了池中什么？
- “同源钱包”中的 SOL 是风险本金还是技术执行费？钱包持币是否属于相同经济受益人？
- 它买入后，后来的跟单者能得到的价格发生怎样的变化？一个现价报价能代表多少可卖 SOL？
- 这些变化在 CPMM、虚拟曲线、不同类型的集中流动性池是否仍成立？何处必须改模型？

不满足于使用术语；要说清楚**资产、权利、费用、库存和信息分别如何改变**。

### 向上推：原子事实 → 经济约束 → 行为激励 → 动态反馈 → 新的专业认知

从池储备和钱包买入的机制继续推：

- 较早的买入改变后来者的成交条件；后来者的追随交易又可能影响早期钱包的退出报价；
- 早期钱包、LP、创建者费用受益者和后续方向性买家的**收益函数可能不同**；
- 在不同深度、不同收费权、不同生命周期，交易量与可持续需求可能脱钩；
- 因而“看见聪明钱买入”可能是**过去已经完成的优势**，也可能揭示**下一阶段尚未发生的经济状态**；两者必须分开。

这时才出现原来目录没有直接写出的跨域知识。**新的知识必须带条件、反向可能和适用边界**，不能只把旧风险换个高级名称。

### 每次往返要试图突破一个“默认认知”

例如旧捷径“资金同源→庄家→吸筹→继续上涨”，反向检查：

- 同源关系可能来自公共服务；
- 钱包同步可能来自公开市场事件；
- 内部转仓不产生独立买盘；
- 价格上涨可能主要来自薄池冲击；
- 早期持有人账面收益未必可变现；
- 后来者买入可能已经改变原钱包退出条件。

这些不是六句“也有可能”，而是**六条不同的经济机制**。必须进一步解释各机制需要什么权利/资金/程序条件，以及条件变化会带来什么后果。

## 3｜每轮研究采用“核心矛盾—专家纵深—跨域回填”的小循环

### 步骤 A：选择一个核心矛盾，不按编号选最小单元

先描述一个**真正影响整体认知**的问题。例如“同样净买入量，在不同池储备下为什么产生不同的价格和可卖性？”它能把 D03 与 D05、D06、D09 连接起来。

选题优先看四项，不造虚假综合分数：

1. **解释杠杆**：这一机制能否同时澄清多个旧误区或下游策略判断？
2. **知识缺口**：当前专家只会列情形，还是已知道协议/经济约束与动态后果？
3. **来源可深化性**：有没有可核对的一手程序/技术/经济资料，能避免凭空讲故事？
4. **下一步决策价值**：弄清之后，会改变后续研究重点、信息源选择或判断边界吗？

若一个题目必须依赖尚未理解的底层原语，先局部钻进 D01/D02；**不必先把 D01 的全部12项排队研究完**。

### 步骤 B：指定一位主专家，固定他要解释的“东西”

主专家首先必须说清：**研究对象**、涉及的**经济利益或资源约束**、要解释的**主要现象**、当前**最容易误解的结论**。不能仅说“需综合多维指标”。

例：D03 E-L2-02 主专家面对的是“订单改变池储备及未来成交条件”，不是无边界地讲整个链上市场学。

### 步骤 C：钻入必要最小单元，只查与当前因果链有关的知识

从现有152项中取出一组“本轮必须深入的”知识单元；其余保留完整目录但不加载。先完成最低限度的**机制守恒**：

- **对象和权利**：具体 Mint、账户/池、资产、授权、LP或fee entitlement，是什么与不是什么；
- **变化与账本**：交易前后有哪些资产/余额/库存/费用变化，哪些内部转移应该抵消；
- **价格与容量**：价格由具体市场机制怎样形成，规模和路径改变时会怎样；
- **行为动机**：为什么不同类型参与者可能选择不同动作，其收益函数和限制是什么；
- **可见信息**：哪些条件可在决策当时知道，哪些只属于事后解释；
- **条件和版本**：技术结论适用于哪个程序/池类型/配置；不能把理想公式普遍化。

不要求每次六项都写满：按具体问题的因果链使用。

### 步骤 D：进行动态推演；让“条件改变”成为深度检验

不是只描述现象；至少尝试这些**相关的条件变化**：

- 池储备/LP深度增加或减少；
- 买入与卖出顺序反转、成交规模变化；
- 有/无手续费、创建者收费权或授权限制；
- 原钱包买入之后出现套利者、其他独立买家或跟单者；
- 从发行曲线迁移到AMM，或多池并存；
- 数据接收变慢、钱包身份聚类被证实是公共HUB。

真正理解机制，应当能解释**哪个结果随条件反转、哪个不变、哪个无法从当前资料推出**。不必编造实际市场样本；理想化数学例子可以服务机制理解，但必须写清假设和边界。

### 步骤 E：跨域专家只对真实分歧作挑战

选择挑战者的依据是“主专家忽略了哪个相互独立的机制”：

- D03 市场专家讲价格：D05 资金专家挑战资金是否真实承担新增风险；
- D03 讲可卖深度：D06 筹码专家挑战自由可处分库存和卖压；
- D03 讲买入价格：D09 执行专家挑战可交易路径、报价与实际fill；
- 若涉及新币迁移：D02 专家指出虚拟/真实储备与协议阶段的变更；
- 若涉及钱包信号：D07/D08 专家质疑观察者时钟与可复制信息。

挑战后**允许撤回或缩小主结论**。不使用多数投票、不统计“专家信心”来冒充客观概率。

### 步骤 F：产生新认知，并回填原单元

每轮至少要给出一种可审阅的**知识增量**，若暂未发现也应如实说明：

1. 修正了哪条旧认知或错误推断；
2. 形成了哪条有明确**条件和后果**的新专业机制；
3. 哪一种不同机制也能产生同一表象；
4. 哪些一手资料已支持协议事实，哪些仍为经济推论或实证假说；
5. 新知识归属 Dxx-Kxx 的哪些单元，对哪些相邻领域的解释产生了变化；
6. 哪一项真正值得成为下一轮的研究核心。

**必须同时保留“主专题文档”和“原子单元回填记录”**：专题保持跨域因果链，单元目录保证不遗漏。不能为了数量每研究一单元就新建一篇空文档，也不把整个横跨领域的认识塞进某一个字段卡。

### 步骤 G：重新选择下一条机制，而非机械执行下一个编号

每轮收尾检查：

- 若核心机制尚有严重矛盾，下一轮继续纵深，不急着转下个 Dxx；
- 若主机制已清楚且主要缺口在另一个领域，迁移主专家；
- 若卡在协议差异，先研究具体协议版本；
- 若只有真实数据才能区分竞争世界，保留理论候选并将“需K2”单独登记，而不停止其它机制研究；
- 若一个主题对其他知识没有新增解释力，优先转向覆盖审计中的高价值缺口。

## 4｜研究足够“深入”的判据：看解释力的变化，不看篇幅

**浅层**：“价格涨了可能是买盘或庄家，仍需验证。”

**中层**：“不同AMM储备决定买入的价格冲击；持仓集中不代表池中有对应的SOL深度。”

**深层**：“说明先后两笔交易如何使储备与报价连续变化；如果LP退出、报价资产波动、其他钱包反向卖出或进入不同曲线阶段，会改变哪一条关系；再解释早期钱包与跟单者因时钟和费用差异拥有不同收益函数。”

一轮专题研究完成至少要满足：

- **机制闭合**：能从最小对象/资产权利出发，追到所讨论市场现象，而不是中间用“庄家在操作”作为黑箱；
- **竞争机制**：至少一个解释实质上不同的世界，并说明为什么它也会产生相似观察；
- **条件反转**：至少指出一个变化会让原结论反过来或失效的条件；
- **专业新见解**：至少一个不是原术语复述的跨域推论，若没有则如实标记尚无；
- **来源与诚实性**：协议事实有版本/来源；推论有逻辑条件；任何实际利润/身份主张仍需独立证据；
- **知识可调用**：专家入口清楚，能按问题找到专题和涉及 Dxx-Kxx，不要求一次加载全部知识；
- **审查可追踪**：新知识增量与仍然未解决的问题分别记录在 Draft PR。

以上是**理论研究审阅条件**，不是 F0–F6 的市场/实盘审批条件。理论解释完成后，若用户继续研究策略预测或盈利，才走对应额外证据审查。

## 5｜具体的知识写入规则

**单次研究不必创建若干新目录**。最多使用既有空间：

- `knowledge/domain/`：按专家撰写一个有深度、能贯穿多个领域的**机制专题**；
- `knowledge/system/`：当前的方法文件、跨域总图及进展/单元映射；
- `knowledge/experts/registry.v1.json`：只增加真正已研究形成的新专业知识入口或改变其思维内容，不凭空增加专家；
- `knowledge/system/whole-domain-atlas.v1.json`：现有ID和领域保持稳定，只有**经过审阅的实际增量**才考虑从 `mapped_unverified` 单独升级；不允许“一个专题引用了这项”就将全部单元批量变绿；
- `knowledge/source-admission.v1.json`：已有的来源限制继续生效，第三方报告未经准入审核仍不是事实；
- `docs/next-steps.md`：知识研究轨与实际 Grok 云电脑部署轨分别跟踪，不能以论文/CI代替真实运行验收。

**例**：D03 专题可同时引用 `D03-K01/K02/K04/K06/K08`、`D05-K02/K05`、`D06-K05`、`D09-K01/K06`。这不意味着十个单元已研究完成，而是标明知识的**来源与影响面**。

## 6｜与当前项目下一阶段的关系

当前唯一适合先进行的**知识研究第一主线**是：

**由 E-L2-02 主导，研究“Solana Meme 中一笔真实资金如何从交易路径进入池子、改变储备与价格，最后影响库存持有人和跟随者的实际退出条件？”**

原因不是“D03 编号比 D05 小”，而是：D05 已有一轮资金职能纵深研究，但缺少与市场价格机制的完整连接；D03 是 D05→D06→D08/D09 的关键桥梁。下一阶段的具体工作包见 [《核心机制研究推进计划》](mechanism-research-plan.v1.json) 与 [《首轮 D03 研究任务》](../domain/D03-market-price-mechanism-research-brief.md)。

**总体顺序**：先钻深市场价格/有效流动性（D03）→ 带着价格机制深入可卖库存/筹码控制（D06）→ 再深入时序/注意力/信息传播（D07）→ 最后把这些知识用于多个独立策略家族和真实执行经济（D08/D09）。D01/D02/D10 的必要前置和 D11 的反证一直按需并行；随研究发现的新矛盾允许调整这条顺序。

**另有一条独立运行交付线**：`docs/next-steps.md` 当前 S1 仍需在真实 Grok 云电脑对固定 SHA 进行离线验收。它不因本轮知识建设而自动完成，也不是我们在 GPT 中开展深层理论研究的前置条件。
