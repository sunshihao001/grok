# KB-003 — 科学反证与可捕获优势的准入层（S1）

版本 0.1.0 · 2026-10-29 · reference_only · 仅用于开发 Bot 研究验收，不是交易规则。

## 核心认知

一个重复出现、统计显著、可追溯的链上结构，和一个**决策时可利用的盈利机会**，是两个不同命题。中间至少横跨三个门：

- **M 机制可识别（Mechanism）**：区分真实交易/签名/转账与模型推测；同源与同步可能是机制，不等于同一身份。用保持时间和节点度的 null、其他普通钱包/已迁移代币对照，以及来源完整度来反证。
- **P 条件预测力（Prediction）**：同一候选的已有身份、资金图或节奏在控制“入场价格、池深、市场阶段、操作者、时间”之后，是否仍对未来结果增加稳定信息？必须以 signal 加入 baseline 的样本外增量为主，不能只看裸胜率。
- **C 可复制净优势（Capture）**：我们的 Bot 在**首次看到**信号之后能否以订单级成本买进，按实际可实现的退出路径变现？必须考虑失败成交、费用、priority/Jito、滑点、价格冲击、排队、复制拥挤和无法退出的尾部。

只有 M 通过，不表示 P 通过。P 通过，也不表示 C 通过。S1 的研究文件不能升级到任何交易权限。

## 原仓最重要的“反直觉结果”

参考仓库的 post_detection_edge 研究：一个独立测试的打二倍命中率从 31.0% 升到 45.7%（N=164），但其预先定义的单笔策略净回报仍约 -23.3%。研究中提到的尾部退出损失和费用足以反转高胜率结论。已知组复现研究在原始对比上显著，但对入场大小/价格做匹配后，增量预测不能排除零，主要策略仍亏损。结构研究有可靠观察，预测研究并不因此自动通过。

这些是**原作者在其样本上的发现**，不是我们的样本实测、可复制策略或未来全部 Solana 代币的定律。特别要保留作者的限制：部分探索研究未进行真正的全新样本 OOS；一些数据集与标签未公开，不能把“可查看代码”写成所有结果已独立重跑。

## 认识时钟、决策时钟和成交时钟

对每条特征同时存：事件发生时间、外部数据实际可见时间、Bot 第一次获取时间、决定时间、模拟执行时间、最终结算时间。严格要求用于决定的每项特征，事件时点与可用时点均不得超过决定时点；**把旧链上交易在未来才查询出来，不算过去已经知道**。

结果变量与特征严格分离。peak、trough、未来回收、未来是否胜出只能写进标签；不能借口“历史复盘”让它流入信号入场条件。paper replay 也必须在独立下一个时段撮合，而不是在 k 期末已知价格中回填 k 期最优成交。

## 实验登记证据卡

每个想法必须有固定的研究编号、原始证据、竞争解释、可证伪条件和结论；初始状态为 HYPOTHESIS，而不是 RULE。

| 字段 | 验收问题 |
|---|---|
| sample_frame | 是所有监控候选，还是只挑已上涨/已毕业/可交易币？分母是否稳定？ |
| comparison & null | 匹配同阶段同流动性同时间的普通币；共享钱包、共同出金是否随机就会出现？ |
| unit_of_independence | 钱包、token、同一运营群、发行批次和日都可能相关；不能把每个钱包当独立样本。 |
| registered_primary_endpoint | 未来价格倍率、定时可成交净 ROI、避免大额损失是不同指标。 |
| multiple_testing_policy | 候选规则数、修正方法、只读一次验证集、探索与确认分开。 |
| source/coverage | 原始签名、来源 blob/ref、HTTP 403/429、分页边界和 missing 原因独立记录。 |
| null_implementation | 除“写明计划”外，还需保存实际置换实现与冻结输出；本 S1 包并未运行。 |
| costs/execution | 买卖手续费、实际成交额、滑点、交易失败、余额、可退出深度、信号时延。 |
| verdict | **SUPPORTED_MECHANISM / UNTESTED_PREDICTION / NEGATIVE_NET / NEED_MORE_DATA / EXPLORATORY_ONLY** 等而非“庄家分”。 |

失败研究保留为 **negative knowledge**，但仅对已经测试的具体样本、假设和成本口径成立；如果机制改变，可重新申请新研究，而不是偷换已有结果。

## 对现有跟单项目最有信息增量的六条路线

1. **捕获窗口图**：观察方和操作者、跟单方各自何时知道什么。研究地址先有信号还是策略已被复制拥挤，边际延迟是否耗尽利润。
2. **钱包级可跟性**：成功钱包的盈利是外部可复制利润，还是自身在发币/起跑、提前注资或内部净头寸下的账面利润？必须对齐同一可执行时点。
3. **负向拦截的净价值**：不因某资金团伙必涨而买；测试识别公共基础设施、虚假深度、撤池和无法卖出的信号是否降低大尾损失，并验证误杀收益的机会成本。
4. **结构时序变化**：首次注资→同批入场→筹码转移→公开信号→外部需求→阶段退出→资金回流；各段单独测，不能用未来才成立的完整图倒推早期预测。
5. **生命周期和价值转移**：对迁移、回踩、第一控盘区、POC/AVWAP 回收等理论，先定义价格源/交易时点/对照与强制退出，不可用“价格碰到位置”代表可成交。
6. **监测研究漂移**：老钱包群识别能过期，网络节点类型会变，平台/费率/延迟改变；规则与来源文件版本分别冻结，支持回滚和负结果重审。

**选择下一实证优先级**：先量化跟单者能观察到信号的时间差与可退出净收益分布（C 门），再决定是否要追更深的操作者指纹（M 门）。这是针对当前项目资源的建议，不是已发现高收益的新规则。

## 研究门禁的最小实现

- 输入：合成离线 fixture，原假设和冻结时间、样本框、对照/null 计划、真实可用时间、假设命中标签和已成交金额。
- 机械审计：冻结早于测试、数据可用早于决策、不可把未来结局带入特征、每条样本注明测量/缺失及失败成交。
- 只输出 TRAIN/TEST 的说明性命中率与平均净 ROI，控制变量与 null 都标记 **尚未真正执行**；程序拒绝把正数自动变为 APPROVED。
- 运行：PYTHONPATH=src python -m solana_meme_os.research_gate --input fixtures/know003-study.json --allow-fixture
