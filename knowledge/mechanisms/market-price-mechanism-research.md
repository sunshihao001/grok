## 1｜主专家必须从这个矛盾开始

> “我不是想知道价格涨了多少，而是想知道：**在何种池子与资产约束下，哪一笔买入改变了可交换储备，为什么后来者付出的真实价格不同，以及早期库存到底能从池里换走多少报价资产？**”

常见市场解释把“资金入场→价格上涨→赚钱”当成一句话。但它实际上包含三件独立的事：

1. **成交机制**：哪个程序以什么余额变化完成了交换；
2. **价格机制**：交易顺序、规模和费用怎样改变下一笔的可得报价；
3. **财富变现机制**：已经持有的 Token 在未来通过何种池/报价和对手承接能换回多少 SOL。

如果第三步不成立，第二步的高报价可能只代表账面价值。若第二步的价格上升来自薄池，不足以证明第一步包含了很多独立资本。

## 2｜专家向下追到的最小知识层

### 2.1 交易不是一个“buy_volume”标签

在 Solana 中要区分：Token Account 的余额变化、钱包的净 Token 风险、池 vault 中储备变化、LP 增减、发币/销毁和交易费。单一 Token transfer 不等于一次独立买卖，且一笔聚合 swap 可包含多段程序/转移。D01-K07/K08 应支持对事件类别的语义解释。

**要说明**：如果 A 给 B 转入 Token 而没有对池执行 swap，为什么 holder 分布可能变化，池价格未必由该转账直接改变？反过来，同一池的交易为何能够改变以后每一个交易者的可得交换比例？

### 2.2 先研究一个明确的价格模型，再研究模型失效

**第一层：理想化、无费传统 CPMM**。分别推导 X、Y 两种储备，以及固定报价资产投入 q 后取得多少 Token。区分买入前边际价格、交易过程中平均价格、交易后新边际价格。再从反方向推导固定 Token 数量卖回能拿到多少报价资产。明确即时完整反向交易在理想无费无其他交易环境中恢复原状态，避免把“买入造成价格冲击”错误解释为该理想模型必然产生即时往返损失。

**第二层：真实 CPMM 费用与储备会计**。核对具体程序版本与 fee buckets：LP所得交易费、协议费、可选创建者费如何计提；vault实际余额与用于定价的有效储备未必完全相同。来源优先 [Raydium CPMM Math](https://github.com/raydium-io/raydium-docs-v1/blob/main/products/cpmm/math.mdx) 与 [Fees](https://github.com/raydium-io/raydium-docs-v1/blob/main/products/cpmm/fees.mdx)。这些是具体文档的版本化解释，不自动推广到 Solana 所有DEX。

**第三层：虚拟储备发币曲线与迁移**。研究真实可提出报价资产与虚拟定价参数的区别；不同曲线类型可能形成不同价格路径，曲线迁移后的池又改变报价条件。来源先读 [Raydium LaunchLab curve](https://github.com/raydium-io/raydium-docs-v1/blob/main/products/launchlab/bonding-curve.mdx)；其它发行平台需独立按版本核对，不以“Pump-style”一词统一全部实现。

**第四层：不同流动性安排**。再向 CLMM / DLMM / 多池路由扩展：有效流动性随价格区间/分箱改变，因此不能无限外推 CPMM `x*y=k`；池价差是否会被套利压平，取决于费用、冲击和套利可用路径。

### 2.3 真正的价格研究必须和卖出方向相连

需要同时区分：

- **买入增量成本**：固定 SOL 预算在某交易后能多拿或少拿多少 Token；
- **卖出净可得额**：固定 Token 仓位在某交易/LP状态下能换回多少 SOL；
- **账面市值**：按某个价格乘供应或持仓数量，不是池子承诺支付的现金；
- **LP 权利和流动性**：池 vault 中资产与 Token 持有人的自由库存不是同类权益。

明确模型讨论的是报价，而非保证可执行 fill；真实延迟、priority费、tip、Token-2022约束、路由错误属于执行阶段的其他机制。

## 3｜要做的动态推演，不是画一幅静态供需图

围绕同一个模型，主专家逐步改变一个约束，再请挑战专家寻找漏掉的约束：

| 条件变化 | 主专家必须回答 | 对应挑战专家 |
|---|---|---|
| A 提前用 q SOL 买入，B 之后同额买入 | B 的取得Token/平均价格为什么变化？A 是否可能改变自己的未来退出条件？ | E-L5-01 / D09 |
| LP 或有效储备改变，其他条件尽量固定 | 同样 q 的买入和固定 Token 的卖出，冲击如何改变？ | E-L3-03 / D06 |
| Token 总供应/自由可卖库存不变，但 SOL/USD 价格变化 | USD“流动性”数值变化是否意味着出现了真实LP撤出或新买盘？ | E-L2-01 / D02 |
| 高成交量来源从长期持币者变为反复套利者 | 交易量很高而净风险敞口不增加时，价格和后续买盘怎么解释？ | E-L3-02 / D05 |
| 某池启用了 creator fee，另一个没有 | 不同主体是否都必须依赖Token上涨才能取得收入？手续费是否会削弱交易者净收益？ | E-L3-04 / D04 |
| 曲线毕业迁移/多池路由出现 | 哪些原有公式仍适用，哪些持仓/池深度变量需要重置解释？ | E-L2-01 / D02 |

不能用“有不同可能性”完成表格。每个情形要指出**条件—状态变化—结果**的具体路径，并说明竞争机制何以产生类似现象。

## 4｜给主专家安排三轮有真实专业冲突的交锋

**E-L3-02 资金专家**：“你说买入导致价格上行，但买入者是独立新资金、同一个机器人循环库存，还是平台执行服务？同样成交量对后续需求意味着什么不同？”

**E-L3-03 筹码专家**：“你推导了某时点买入后的价格，但早期钱包还掌握多少真正能卖出的库存？池 vault/LP头寸和托管账户会怎样使你误判抛压？”

**E-L5-01 执行专家**：“你算的是理想池储备，还是我在源收到信号后真正可以得到的买/卖报价？我的仓位越大、其他交易越多时，哪些收益结论不再成立？”

这些对抗应改变主专家的模型或条件，**不能**写成大家对同一解释表示认可。

## 2026-11-13｜D03/D06：市场价格、可卖库存与纸面跟随成本不得混成一个指标

[当前P1/P2知识核查](../references/p1-p2-knowledge-reconciliation-20261113.md)与 [meme-观察者门槛](https://github.com/sunshihao001/meme-/blob/main/specs/mql5-fcz-reclaim-model/structural_observer_vs_quant_system_gate.md)表明：FCZ、POC、AVWAP、Wyckoff吸筹派发、二次接受等可以帮助构造**不同市场机制解释**，不是已核对的资金控制者成本或真实流动性担保。

- 同一Mint在建池/曲线/迁移后，价格、Token与报价资产储备以及可卖出性具有不同合同。跨池行情价差≠扣费后的可套利价差；库存向池转移≠可证明的市场Sell。
- 当前 `facts.network` 的 `knownRawTransferred` 是有界原始Token转账总量，可能多跳重复；不是池内Swap总成交额、独立买盘、资金流入或可卖库存。
- Token-2022 TransferFee可能扣留部分转入，LP拥有的资产权利、池Vault余额、Token Account的实际owner也未从单一转账指令得到经济主体答案。
- 研究跟单可行性时，实际可获报价、信号首次可见时间、交易延迟、滑点、优先费与失败订单比任何静态成本锚更接近可检验对象。当前 `followability-replay.mjs` 仅审核纸面收据，不代表已经得到真实执行成本或市场Alpha。

仍可提出“某种库存/需求变化可能导致价格反应”的明确条件假说，但必须说明所需的市场基线、池子、历史时间与替代解释，不用资金图代替价格机制。
