# R001-B｜从地址追踪到经济仓位：机制深研与知识转化 V0.2

状态：研究写作草稿，2026-10-31。归属：`skills/solana-meme-expert-writing`。此文为只读研究，不修改交易规则，不声称已获得可交易优势。

## 研究命题

原有钱包跟单系统把“地址行为”和“可复制收益”紧密相连，但两者之间至少隔着资产所有权、仓位完整性、时间可得性、价格形成机制和成交约束。专业研究不应该仅问“某钱包买了什么”，而要问：

**这笔交易属于什么经济活动？它所关联的真实风险敞口经过哪些地址和市场状态转移？我们在看到这条交易时，还剩下什么可以实际捕获的信息？**

这不是要求将所有关联地址武断合并为一个“庄家”。应分别重建**能证实的资产路径**与**待推断的经济主体关系**。

## 1. 原始证据：一个“狙击钱包”的余额变化无法表示完整经济结果

在 `Why-Solana-Memecoins-Are-Over/economic_mechanics/results.md` 的特定协调样本中，TRAIN/VALIDATION 两组中约 75%/79% 的狙击地址在告警后的 30 秒内已将代币移出；对已移出者，主要路径为向另一地址转账而非直接卖出，分别约 83%/81%。其中一组常见行为是：资助地址向多个执行地址发送 SOL，执行地址参与首个创建 Slot 的交易，随后代币被转移、SOL 回流，并在后续发行再次使用。

原研究同时明确：接收代币的地址最终在什么价格完成卖出、卖出所得流向何处，尚未充分观测，所以**没有计算该群体完整利润**。这对旧 Hermes 的 `learning/10.md` 钱包角色、`learning/11.md` 同源关系及 `design/Skill4-筹码控制权状态层设计.md` 库存状态模型提供了直接的深化方向。

问题不在于有没有地址标签，而在于钱包 A 向 B 转移代币时：
- 已发生的是资产转移；还没有从这条交易单独观察到对市场的主动卖出。
- A 的余额下降，不等于相关经济仓位总库存下降。
- B 以后卖出，也不自动证明 B 与 A 由同一个人控制。
- 由资金资助者向 A 打款，不等于资助者承担了该仓位的全部风险或享有全部利润。

**新的本体区分：** 资金流向、代币转移、市场买卖、经济风险转移和控制关系是五种独立的边；不允许使用一条 `same_source` 边代替后四条。

### 资产路径与经济主体要分两张图

**资产事件图 G_asset：** 节点为带角色和时间戳的地址/账户，边是交易签名可证实的 SOL 付款、SPL Token 转移、Swap 的输入/输出、创建/关闭账户及费用。边记录 Slot、资产单位、数量、交易对手和来源。

**主体假设图 G_entity：** 节点是可能的经济主体，边是“疑似同控”“使用共同服务”“可能委托执行”等关系。每条边必须具有支持、反证、观察范围和未知部分，不可直接回写成 G_asset 的确定事实。

分离这两图的收益在于：后续核实 B 是交易所或共享服务商，不需要否定此前正确记录的 A→B 转账，只需撤回主体归并假设。

### 一个纯粹用于解释的示意

假设地址 A 使用 SOL 买入 100 单位 Token，把 80 单位转至 B，把剩余 20 单位留在 A。后来 B 在市场卖出了其中 30 单位。

能观察的是：A 买入 100、A 转出 80、B 卖出 30、A 和 B 仍有库存。不能直接从 A 的“卖出为零”断定这组经济活动没有兑现利润，也不能把 B 的卖出所得无条件计到 A 名下。若 A 与 B 的经济关系未知，应保留各自账本及“可能共享仓位”的待验证关系。

示意数字不是实际链上数据。专业代码必须进一步区分转移、销售、铸造、销毁、转账费、Token-2022 特性和未知余额变动。

## 2. 为何资金循环不是完整主体归因

在该项目的 `funder_network/results.md` 中，研究者继续追查资金收集与回流：其限定样本包含 62 个关键资金钱包、24 个操作群，观察到资金进入高活跃路由账户以及再次供给原网络的行为。部分共同路径表现出高度重复，但研究也发现“不同操作群共享非 hub 节点”并不比随机对照更密集。

这一证据更适合支持“存在重复使用的经济执行结构”，不能直接写成“所有操作群都是同一主人”。研究甚至指出，一个跨群的资本网络与掌握密钥的执行服务，均可产生某些相似观察结果。

在专业写作中，应按证据强度分开四层：
1. **已发生：** 某地址向另一个地址发送多少 SOL；某个签名确实授权了何种操作。
2. **统计异常：** 在清楚的样本和 null 模型下，相关行为显著偏离合理对照。
3. **行为角色：** 基于可重复行为暂称 funder、sniper、token recipient、router、collection wallet。
4. **经济归属：** 哪个真实主体获利、谁持有私钥及有何意图——若没有足够证据，则维持未知。

尤其要防止“跨几跳都关联”产生无限扩张的同控簇。基础设施 hub 的存在会使实体图迅速错误合并，导致错误估计同一群体的库存、卖压和风险。

**知识转换：** 从“同源组置信度越高越该关注”改为“资金图闭环程度、基础设施排除完整度及经济归属未解程度分别报告”。

## 3. 把“钱包 PnL”拆成可审计的现金流与库存

外部复制者需要先知道原地址的利润数字是否包含转移资产的成本和后续处置。应先选择边界，再计算。边界可以是“单一地址”，也可以是“已有独立证据支持的经济仓位集合”，两种结果不得混报。

从一个定义明确的 Token 账本开始：

```text
期末 token 库存
= 期初库存 + 已确认买入 + 已确认转入 + 铸造/领取
  - 已确认卖出 - 已确认转出 - 销毁/费用 - 其他已解释变化
```

在相应事件数据不完整时，上式应产生 `unreconciled_delta`，而不是通过虚构内部成交来凑平。SOL 及其他报价资产也需独立核对。买卖发生在 AMM 时还须从真实交易事件和 Token 余额变化识别输入输出；单看一个 Token Transfer 不必然表示交易所执行。

对于确认边界内的经济仓位，可以分别计算：
- `external_cash_in/out`：边界外进入和流出的资产、估值依据及时间；
- `realized_trading_cashflow`：可关联成交的外部买卖现金流，扣交易成本；
- `remaining_inventory`：仍持有及待核实的代币数量；
- `marked_inventory_value`：按明示的参考报价估算的未实现价值，并且**单独标注不可等价为可退出收入**；
- `unattributed_transfers`：无法判断经济归属的地址转移及相关资产。

若边界未闭合，不应输出一个貌似精确的“实际实体净利润”。可以输出已证实的净现金流范围、剩余库存和未知部分；没有充分约束时连上下界也可能不可计算，直接保留 UNKNOWN 更准确。

在此基础上，原地址“盈利”至少可拆为：交易能力、价格路径、库存重分配、交易成本、未闭合转移和估值方法。后续跟单可复制性只能依据**当时对外可观察的行为信号**另行建模，不可直接复用事后实体账本。

## 4. 历史利润的来源：竞争性机制与可区分的预测

| 机制假设 | 为什么历史钱包可能显得盈利 | 什么新证据真正有判别力 |
|---|---|---|
| 信息筛选优势 | 交易者提前识别后续新增需求 | 冻结筛选时间，控制市场阶段后仍产生独立样本外预测 |
| 执行位置优势 | 在价格形成早期先成交，享有他人无法复制的成本 | 对齐首次可见时点、原成交价、真实可得报价及不同延迟的净收益 |
| 资本/库存网络 | 利润反映跨地址调拨、特殊角色与不同资产流 | 仓位转移的闭合度、公共基础设施排除及关联卖出对价 |
| 幸存者/计量偏差 | 只筛到赢家、漏掉失败仓位、把未知算零或用后验标签 | 冻结完整候选集合、跟踪所有损失事件、做时间与主体簇级隔离 |

以上机制可重叠，不能按“指标越多越真”加权。原 Hermes 的控制权状态设计把 `state_probabilities` 和若干控制分数形式化，但其样例数值和示意权重本身不等于已由真实结果校准的概率。对我们而言，更有用的是保留“状态观察”和“规则干预”分层，并将每个假设转换为不同的未来观察预测。

在市场状态方面，`meme-` 的第一控盘区理论把成交密集区和后续第一波上涨相连；若“后续上涨”参与当初区域的定义，就不能反过来用该事后区域证明当时已经可入场。应当保留一个当时可计算的 `candidate_zone_at_t`，事后验证单列，不参与 t 时点的模型训练特征。

### 可证伪的新推断 A：仓位可闭合度影响钱包标签的可靠性

假设：频繁转移库存、但缺少完整接收者卖出与资金对价的地址，其历史盈亏标签更容易与真实经济仓位结果偏离。

如果第三方平台的收益算法已完整处理转入和转出，且经过独立核算后并无明显偏差，这一机制应被否定或缩窄，而不能继续用“可能隐藏筹码”兜底解释。

### 可证伪的新推断 B：仓位转移行为可能是风险信号而非跟买信号

某类重复执行网络的资产流转即使不能为后来者提供买入优势，也可能对后续可卖出库存及交易承接风险提供信息。必须检验：在真实观察时点控制价格、成交量和池子深度后，这类行为是否仍预测后续流动性或卖压恶化。

若控制市场微观结构后增量消失，则它只是价格和市场阶段的另一种投影，而非提前信息。

## 5. 把市场信息优势转换成“观察者剩余价值”

同一个钱包的历史利润、交易预测力和跟单净价值不是同一个目标变量。

定义四个时间：
- `t_event`：原钱包交易事件发生；
- `t_available`：原始链上事实或接口字段第一次可供我们观测（需真实采样验证，不能用后来查询代替）；
- `t_decision`：监控实际做出判断；
- `t_fill`：按明确报价、路由及失败处理规则计算的可能成交时间。

在事件选择、延迟和交易规模一致的条件下，可检验的对象是：

```text
copyable_value = E[net_exit_value - net_entry_cost | I(t_decision), size, execution_policy]
incremental_value = copyable_value(with_wallet_behavior)
                  - copyable_value(market_only_baseline)
```

这里的 `I(t_decision)` 只含当时确实可用的数据；净值来自对已冻结的执行与退出政策做独立模拟，尚不是实际观察到的利润。不能凭历史峰值计算退出价格，更不能把原交易者成本当成跟单者成本。

外部 `post_detection_edge/results.md` 对选定的 1,657 条检测告警做时间安全的后续价格研究。其 TEST 中一个信号将“15 分钟内触及两倍”的比例从 31.0% 提升至 45.7%（信号 N=164），但该研究的主要交易政策仍未产生可确认正净收益。这是“结构/预测/经济价值必须分离”的强方法证据，不等于其他钱包策略没有机会。

该项目 `post_detection_edge/pitfalls.md` 还说明：如果监控停机后仍把已止盈者当有效样本、把未到止盈者因缺失价格轨迹排除，就会在样本层面偏向成功。对 Grok 而言，缺失时窗不仅是运维故障，也是收益统计的审查条件。

### 可证伪的新推断 C：信息与执行之间存在条件性剩余窗口

假设：早期钱包的可复制价值主要由“首次可见时尚未被价格吸收的信息”和“当前池子可执行深度”共同决定，而不只由地址历史 PnL 决定。

可能的反例：某些后续注意力扩散很慢、流动性持续改善的发行阶段，即使观察较晚也可能仍有剩余收益；另一些场景在刚检测时机会已经消耗。应按市场阶段和交易规模分别估计，不能简单套用单一的“信号最多延迟 10 秒”阈值。

验证时将所有案例都放进同一个观测顺序，要求所选时点真实可测：

```text
原始事件 → 确认/接口可用 → 本地收到 → 决策 → 进场成交 → 退出成交
```

然后对固定策略，按延迟、持仓时长与池子深度进行条件评估。若加入钱包特征相比只用当时市场信息的基准没有独立贡献，则“该钱包提供可转移优势”的假设不成立。

## 6. 第一个可执行的只读研究实验：不要先搜赢家

**抽样：** 冻结某一时期可实时检索的 Solana Meme 发行及钱包候选集合；把未达预期、没有成交、监控中断或资金路径无法追踪的事件也纳入台账。对同源/跨事件重复主体采用簇级评估，避免让同一执行网络的多个发行同时出现在训练与评估中。

**数据：** 逐笔保存签名、slot、Token mint、资金/Token 账户变化、Swap 是否真实发生、池地址与资产单位；若用 OKX/GMGN 接口，另记录其响应时间、字段定义、实际接收时间和缺失。OKX 的 `okx-dex-market` 文档可提供只读代币、交易和钱包分析入口，但**文档中的能力还需要真实响应验证**，不能将 `requestTime` 自动等同于历史首次可用时间。

**比较：**
- B0：仅使用当时的价格、流动性、成交及发行阶段；
- B1：B0 + 当时已可用的原钱包历史表现/平台标签；
- B2：B1 + 已核实仓位流、主体关联不确定性与行为时间；
- B3：B2 + 预先定义且不使用未来数据的市场状态交互特征。

每组采用相同事件全集、成交政策、资金量、费率与数据覆盖规则。评价同时记录预测提升、净交易结果、不可成交比例、最大不利路径、缺失率与错误归因案例。若 B2/B3 仅改善文章解释、不改善独立样本外结果，保留其机制洞见但不发布新交易规则。

**首个审查样本：** 既有 `meme-/07_样本标注/样本记录/FCZ_C_0001.md`（TIRED）与 `FCZ_D_0001.md`（WORLDCUP）有部分 GMGN 原始快照，尚不能独立验证资金仓位和实时收益。可先用它们检查接口字段口径、时点可比性和“已标注案例 vs 真正完备案例”的区别；再选择具备原始交易签名的真实钱包群做仓位路径回放。不能把这些尚待核验的案例包装成成功或失败的盈利证据。

## 7. 给 Grok 的研究语言，而不是新的买卖规则

研究问题：
> 一组地址的代币余额减少。哪些减少来自市场卖出，哪些只是转移？是否有可独立核实的经济主体归并证据？这些库存变化在当时是否已被观察到？它们能否在控制市场状态后解释未来供需变化，且对外部观察者有可执行净价值？

Grok 的合格输出应包含：
- 已核实的转移和 Swap，分别给出处和时间；
- 经济主体关系属于哪种假设，是否排除了公共 hub；
- 未闭合仓位和无法确认的实际收益；
- 对同一现象的最强竞争机制及下一条高信息量观测；
- “解释过去”“事前预测”“可复制净价值”三个状态分别报告。

不合格输出包括“多钱包同源，所以庄家控盘且可以直接跟买”“原地址转出 80% 就等于卖出 80%”“高收益地址未来必然盈利”。

## 8. 新认知边界与结论

本篇已完成的是**专业知识转换**，不是市场验证：

- 将地址层面观察转换为资产图和经济主体假设图；
- 将历史钱包盈利转换为需要核对仓位闭合度的经济结果；
- 将地址评分转换为可被竞争机制推翻的预测；
- 将“信号准确”转换为必须考虑可观察时点和退出约束的净收益问题；
- 将“不能跟的地址”扩展为可能但尚未证明的库存风险信息源。

**后续最重要的取证问题：** 在一个真实发行事件中，原始钱包的 Token 转移能追踪到哪些卖出与资金去向？这条资产路径在外部首次可观测的时刻，是否已经产生可利用的未来信息？
