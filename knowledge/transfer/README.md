# Knowledge transfer inbox/outbox（非自动部署）

这里只保留课程清单、学习材料与反馈格式。未来 Grok 交来的真实反馈应该经过审查后作为任务特定附件/报告归档，**不能修改原始证据事实**。

请勿把私人 GPT/Grok 全量聊天、云端登录凭据、私钥、未授权接口密钥或含敏感标识的原始资料上传公共仓库。对于第三方受版权限制的研究，仅引用原文和固定版本链接，知识单元由独立解释构成。

本目录中的 C0–C4 是**课程深度**，不是 L0–L7 领域知识层，也不是 F0–F6 市场证据门槛。

任何新的知识单元先以 `draft` 提交；校验器拒绝把课程通过标为真实市场验证或 B07 发布授权。课程获批准学习需要明确的 PR 审查记录，Grok 反馈应另经审查才能确认为课程测试通过。

开始阅读 `docs/gpt-github-grok-knowledge-loop.md`。
