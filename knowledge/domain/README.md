> **状态**：`domain_method_candidate`，为审阅中的专用知识包。不是已完成 K2 实测、已证明正收益策略或已冻结 B07 规则。不同的 K1 来源受 `knowledge/source-admission.v1.json` 管理；被标记 review_only 的后期研究不自动成为本包事实。没有迁移整库历史文本。

**优先阅读这份纵深成果**：[E-L3-02 资金组织、经济利益与跟单价格反馈](L3-E-L3-02-capital-organization-incentives.md)：不是再扩写“同源未必同控”，而是追问同一笔 SOL 是本金、执行费、托管、LP 还是创建者收入；区分执行授权与最终风险承担；将同一个资金图推演为四种不同经济组织；接入 Raydium CPMM 可选 creator fee 与交易手续费机制；用无费 CPMM 的严谨算例说明领先买入怎样改变后来者的买入价格。**它是已有 E-L3-02 的纵深知识，不是新专家、已获利的实证策略或强制全部专家同时读取的文档。**

## 不是读完全部才开始研究：按问题取用

- **新币突然出现**：D01 + D02 + D03 + D10；如发现集中/关联，再追加 D04–D07。
- **钱包值得跟吗**：D04 + D07 + D08 + D09；若涉及资金/团队，追加 D05/D06；D10/D11 贯穿。
- **资金同源是不是庄家**：D01 + D04 + D05 + D06 + D07；不自动推导到 D08 的盈利判断。
- **为什么策略回测很强但不能赚钱**：D08 + D09 + D10 + D11；必要时 D02/D03 查流动性状态。
- **监控告警到底意味着什么**：先看产生告警的领域，不把研究解释自动当作交易规则；D12 只保证规范输出和回流。

**读取纪律**：只加载本问题涉及的 1–2 份专业内容和需要的旧卡，而不是把四篇全部放入常驻 Prompt。K0 保持短；本包是可复用的领域方法（K1 内部整理），尚非 K2 现实观测。

## 第一轮优先完善的真实缺口

1. **D01**：现在没有专属主知识卡；已有文档的交易签名、token account、内层指令及资产净额应转成程序可复算的 `swap/transfer/LP` 分类。
2. **D07**：现在没有专属主知识卡；需要跨币/跨时段行为案例和“共同事件≠共同控制”的负对照。
3. **D08/D09**：当前一个 `reclaim-theory` 卡与一个 `token-security` 卡无法覆盖真实跟单盈利与退出研究。必须区分钱包收益、跟随者可见性、两侧成交成本。
4. **D10**：先获得至少一份来自 OKX 或 RPC 的真实只读样例，验证字段单位、时间及覆盖；不要把本知识文档中的规范化字段误认为现有 CLI 已提供。
5. **D04–D06**：在有真实数据前，钱包图谱和所谓控盘只能作为候选解释，尤其谨防历史共享 HUB 与经济主体混同。

## 每次专业研究的最小输出

```text
研究对象：Mint / Wallet / 事件与时间
涉及领域：Dxx（仅必要部分）
已观察事实：原始签名、字段、单位与获取时间
专业机制：候选解释和成立条件
相反机制：至少一种合理替代
关键缺失：最有助于改变判断的一项数据
策略判断：解释 / 可预测 / 可交易（分开）
当前状态：未知、只读观察、纸面研究或阻断
后续动作：一个可执行的只读验证动作
```
