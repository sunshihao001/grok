# Rules | Monitoring and Research Gates

Current rules/monitor.v0.json contains **experimental single-Mint snapshot thresholds only**. They are not statistically validated abnormality detectors, Jito bundle evidence, proof of a market operator or trade signals.

The market-wide system must keep five independent questions:

1. **Input and provenance:** signature, slot, instruction, token owner, units, source, window and availability verified?
2. **Observed behavior:** funding fanout, same-slot buying, token consolidation, recurring cross-Mint actor groups? At this stage report a *candidate*.
3. **Normal vs abnormal:** appropriate baseline with population, stage, activity, common public triggers, CEX/infra hub controls and error rates?
4. **Market risk:** token authority, liquidity, inventory flow, migration, developer history and plausible downside?
5. **Paper trading value:** data known at decision time, out-of-sample predictive contribution, actual slippage/fees/latency and executable exits?

Passing one does not imply passing the next. No unapproved rule upgrades, live trading or automatic publish. Existing thresholds remain unchanged pending evidence and human review.
