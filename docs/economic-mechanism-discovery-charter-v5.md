# 正式研究主线 V5｜经济机制生成、跨领域认知合成与主动反证研究

> **定位**：项目的研究操作原则，不是市场预测的既成事实，也不要求立即启动大量 Agent。  
> **日期**：2026-10-31；仅草案分支 `docs/cognition-knowledge-conversion-v1`。  
> **上承**：[机制判断与认知合成 V3](economic-mechanism-synthesis-and-judgment-v3.md) → [快慢双循环运行架构 V4](dual-loop-research-runtime-architecture-v4.md) → 本 V5。  
> **当前工程边界**：M2 仅对输入的规范事件做离线监控；专家图和研究调度可执行确定性规划；无真实全市场 RPC 解码/长期运行/跨 Agent 自动分析/自动实盘。

## 一、该主线究竟增加了什么能力

**市场事实 → 行为结构 → 竞争经济机制 → 专业矛盾 → 判别性证据 → 修正/反证 → 新知识/运行规则**

这不是按固定“已知庄家标签”套模型，也不等于让十几位专家复述相同链上事件。我们要识别三种有区别的创新：

1. **生成新研究对象**：从地址实体转为非公共经济角色的时序活动片段，如“注资→Token 买入→仓位归集→Swap/LP/手续费→回流→跨 Mint 复用”。
2. **生成新竞争机制**：同样的 SOL 流入、同 Slot 多钱包或价格上涨，可能来自 LP 释放、普通机器人竞争、自身价格冲击、新外部需求或运营群体。机制必须预测不同的后续证据。
3. **生成新证伪动作**：主动选取能使两种机制给出不同结果的签名、观察时点、资产守恒分解或匹配正常市场；证据不支持时判错、降级或撤回相关机制，不用模糊评分遮掩。

**允许大胆提出任何新机制，但不能跳过“是什么事实、在哪里有分母、谁可以推翻它”。** 过去明确错误的推断规则（如 UNKNOWN funder 当独立、余额减少当确定卖出、没有 System Transfer 当没有 SOL 收入）直接归入规则错误，不再用“倾向不可靠”继续保留。

## 二、触发新机制研究的六个入口

| 原始触发 | 跨专业矛盾 | 研究目标与最低反证 |
|---|---|---|
| 新 Program/无法归类的真实指令 | 既有事件本体解释不了余额变化 | 解码外内指令、账户所有权与资产守恒，确认是否需新事件类型 |
| **频率和价值的反转** | 某标签按次数罕见的子类，却主导资产金额 | 切分业务来源，再检查源程序是否为同一经济仓位的释放、收入还是新增外部资产 |
| **历史覆盖与零值耦合** | 无历史数据的地址被标为“无注资/新地址/独立” | 分页回放及正常对照；剔除观察错误，不能把 UNKNOWN 当真实 0 |
| 资金图与库存图互相矛盾 | 资金来源显示共同节点，但 Token 收益/库存未闭合 | 对照公共 hub、代币账户 owner 与资金环路，提出多种主体组织解释 |
| 价格反应无法由已观察交易解释 | 交易执行、LP 变化与实际池储备不守恒 | 检查多池路由、池状态、Swap/WSOL、延迟与第三方需求；不能把残差自动叫“操盘” |
| 动态正常基准出现结构性变化 | 旧阈值预警暴涨或异常消失 | 与相同发行平台、协议、机器人活跃度、市场阶段和取数覆盖的匹配对照比较 |

**核心区别**：前两个“反转/缺失”已从公开案例中观察到了派生数据层面的现象；后面的机制属于新的可检验解释，不是已经被链上原始 RPC 证明的事实。

## 三、R007：第一项可复算“知识叠加发现”实例

一手来源：`sunshihao001/Why-Solana-Memecoins-Are-Over@9a7ad51d56328e91e67e3f531d6744307d0ee68b/data/trace_h2w6/e2_funding_h2w6gm6jz.json`。读取全量公开**派生** JSON 并对 `wallets[].inflows[]` 重新计算，区别于直接复述作者摘要。

本研究 cohort 中 `nature=financement` 共 **61 条，858.582182029 SOL**：
- 53 条源标签 `SYSTEM_PROGRAM|TRANSFER`：**98.670927181 SOL**（11.4924%）；
- 8 条其他程序来源：**759.911254848 SOL**（88.5076%）；
- 其中 4 条源标签 `METEORA|REMOVE_LIQUIDITY_BY_RANGE`：**739.476844669 SOL**（86.1276%）；
- 其余是 Magic Eden 市场指令和 Mayan Bridge 等程序的正向余额变化，均尚未进行本轮原始 RPC 重放。

**已经可以判错的推理**：“`financement` 标签的总金额 = 858.58 SOL 的直接外部钱包注资”。该等式不是源表实际支持的语义，且会让**业务类型仅占 13.1% 的少数记录主导全部资金量**的事实完全消失。

**仍然值得大胆研究的机制 H**：“部分被称为融资的钱包资金，可能主要是先前 LP/其他经济仓位释放的资本，而非独立外部投资。”这是一个跨领域资本组织假说，尚不能称已证实。至少要用四项辨别性核查：真实池流动性撤出签名的外/内指令、LP 份额/原始存入者、Token 与 SOL 两边余额守恒、释放资金是否流向后续 Mint/新执行地址。

**第二项独立现象**：钱包起点历史覆盖 21 个（21 个都有 `financement` 标签记录）；未覆盖起点 19 个（其中 15 个**没有**该标签记录）。这表明“未观察到融资”与“没追到钱包起点”高度关联。它不足以证明真实链上资金缺失必然由 RPC 截断造成，但足以禁止使用“0 条融资”证明“独立/没有历史注资”。

**不应得出的结论**：实际钱包同控、庄家资金循环已成立、已确认真实 LP 款源、存在可交易优势。以上金额属于旧研究派生数据及其 `tx_source` 业务标签。

## 四、R007 的最小实现与可推翻状态

新增 [`mechanism_discovery.py`](../src/solana_meme_os/mechanism_discovery.py)，离线接受同格式历史来源 JSON，执行：

1. 复用旧 `cashflow_semantics.audit_funding_table`，校验来源表、钱包和历史覆盖标志，防止把缺失当 0。
2. 按来源业务类型同时计算**事件数比例**和**SOL 金额比例**，用 Decimal 保留 9 位来源精度。
3. 在“少数类型按次数不是多数、却按价值占主导”的条件下产出 `COUNT_VALUE_ECONOMIC_TYPE_INVERSION` 研究对象。
4. 对 `genesis_reached` 已知/未知样本分别统计 0 流入和有流入人数；仅当样本足够大且条件差明显时，产出 `HISTORY_COVERAGE_RECEIPT_SILENCE_TENSION` 数据语义调查对象。
5. 输出按 SOL 金额选取的**建议独立复核签名**、多个竞争机制和“哪条原始证据能够否定它们”。
6. 任何输出都是 `PUBLISHED_DERIVED_TABLE_NOT_REPLAYED_BY_THIS_MODULE`，`no_trading=true`，不能直接升级为“市场异常已证实”。

**关键不是硬编码这个案例的地址或 858.58 数字**，而是保留一种可以复用的专业思考形式：同一研究标签从“交易计数、资金规模、资产性质、历史覆盖、专家语义”多个视角看，若出现反转与矛盾，自动产生新研究问题，不自动发明操盘结论。

可运行接口（需另行从原项目取得对应 JSON）：

```bash
PYTHONPATH=src python -m solana_meme_os.mechanism_discovery \
  --input data/e2_funding_h2w6gm6jz.json \
  --output .runtime/R007-mechanism-discovery.json
```

仓库中 `data/e2_funding_h2w6gm6jz.json` **不是自动存在的文件**；须明确提供完整来源数据。配套 `tests/test_mechanism_discovery.py` 使用合成输入检验反转、缺失历史、不完整业务类型、资金精度、不开仓及确定性输出等约束。

## 五、专家怎样分工而不是投票

**观察法证（Data/Chain）**保证原始签名、Token 与 SOL 指令/账户/金额完整；**资金与经济网络（Graph/Wallet/Token）**区别外来注资、LP释放、收益兑现、公共来源和资产中转；**市场微观结构（Liquidity/Inventory/Regime）**解释真实池深、价格自冲击、清算压力；**统计与因果（Statistics/Causal）**检查正常基准、缺失机制、样本外稳定性；**独立 QA 与知识工程（Review/Knowledge）**有权直接判错误规则、撤销依赖它的下游结论，或新增事件类型。

一位专家的意见不自动加强另一个意见。**必须提交不同来源的可观察事实、至少两个竞争机制、下一条最有差异的证据，以及被否定时要撤回哪些结论。** 任何无真实新证据的“多数专家同意”不增加证明力。

## 六、模型与系统的知识状态应不同

| 状态 | 使用条件 | 应允许什么 |
|---|---|---|
| **确定规则错误** | 原理、协议或逻辑有明确反例 | 直接废止/更正依赖的规则，无需礼貌性保留 |
| **派生事实已复算** | 重算来源数据表，可明确字段、时间窗、来源版本 | 用于生成实验，不宣称原始链上真值 |
| **竞争经济机制** | 对观察给出不同可测预测 | 充分演绎并安排高信息量取证 |
| **真实交易源核验** | 指令/余额/池状态独立重放且守恒 | 可确认限定事实，仍不直接证明同一受益人 |
| **正常基准与机制检验** | 事前定义总体、留出期、条件对照和失败条件 | 可评估风险/机制效力与泛化 |
| **可用市场能力** | 实际应用指标胜过简化方法，运行边界明确 | 监控/开发者/风险模块可版本化发布；交易价值仍须另过纸面成本测试 |

## 七、怎样从 V4 真正走到 V5

V4 已通过 GitHub Actions 108 项离线测试，说明**对已知候选做有限调查计划**的工程闭环存在。V5 新增的是对专家分类/观察数据自身矛盾的**机制发现入口**，不是独立持续运行的新 Bot。真正需要的下一步：

- 选定的候选 M2 案件和本 R007 研究对象共用签名复核预算，但仍保持不同的源/时间/资产作用域；
- 将 R007 两种具体张力写入版本化研究卡，明确哪项被直接推翻、哪项只是新假说；
- 对选定签名做真实 Solana RPC 取证后，首次量化**源业务类型被纠正的资产比例**以及“历史未知 → 错误独立钱包”发生率；
- 在普通 LP/机器人/桥来源的负样本中复测方法，确认只要见到高金额 LP 退出并不自动叫操纵；
- 最后用同预算的固定阈值/普通图谱/语义反转+主动反证比较事实准确度和成本。失败则修正方法，不靠专家叙述保护它。

**终点不是拥有一个万能解释框架，而是每个新证据都能真正改变哪个经济模型应保留、哪个应废止，以及下一次最值得调查什么。**
