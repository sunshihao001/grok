## 最先做什么
1. **只读安全及运行要求检查**：梳理自动运行/AI付费/真实交易/私钥/签名/网络调用，建立可证明的安全边界；Node>=24.16，确保运行环境支持。不要因README宣称本地免费就假设所有路径无成本。
2. **单 Mint 完整业务纵切**：从 Blix 已有 Mint/钱包/API 读取真实数据，审查身份、转仓与资金关系；优先通过 PumpTrace/Million/OKX 等成熟服务补证据。保留时间、来源、分页、UNKNOWN 和负例。
3. **再扩展观察**：对保存的群体比较6/12小时与历史行为，验证多钱包/多池、队列断流、去重和重启恢复。
4. **UI/AI 解释**：依托原 Coin Sheet/Tracker/Research 展示经济事实、竞争解释、状态和反馈；不要先造第二套交易终端。

**实测验收条件**：完整记录运行版本/依赖/来源、签名+动作身份、TokenAccount与owner、费用/权限、历史缺口、异常恢复和真实成功/失败。源码查阅与单测不能冒充主网实跑；不启动交易/签名/付款。
