## 旧八层/七 Skill 的继承与纠偏

在 `sunshihao001/-/docs/trading_system_stage_layer_design_v2.md` 中：
- 第 0 层安全宪法仍作为**所有专家的横向约束**，不受任务路线影响；
- 第 1 层标准化应扩大为按 instruction 精度与信息可得时间的证据合约；
- 第 2 层实体归并应降为**允许未知的经济控制假说**，资产路径和协同统计先行成立；
- 第 3 层结构证据需要**同类型正常基准、独立信号与反证**，不由钱包归并强制启动；
- 第 4 层库存控制需允许不明库存、CEX/LP/服务商及边界未知，不能强行让已知实体权重合计为 1；
- 第 5 层生命周期可独立于实体确认工作，价格结构一定遵守事前可得性；
- 第 6 层动机只做竞争假设；未经校准不能输出“某种真实意图的 92% 概率”；
- 第 7 层 Gate 要拆开**数据真实性/完整性、风险已知、研究价值、纸面交易可行性**，它们可以得出不同状态。

历史七 Skill 都可以作为专业知识来源，**但不是必须按顺序运行的固定流程**。面对安全风险、LP 变化、开发者重复发币或跨币资金流，项目应先选择能最早区分机制的专家和数据。

## 实验上最应该优先解决的五个认知瓶颈

1. **市场总体与观测范围。** 如果只看被检测器筛选的事件，就不知道真正正常和异常的分布；先建立未选择样本的市场事件全集与时段覆盖，才有可能给“异常”定量。
2. **原始交易语义。** 余额、签名与平台标签尚未被统一解码成“实际发生的转账、Swap、LP、权限变化”；先有链上法证才能让经济解释成立。
3. **主体/服务商误归并。** 公共资金来源既可能像“统一操盘”也可能仅是共享基础设施；需要支持和推翻双边假说的证据图。
4. **市场影响的因果方向。** 一组早期买入本身可以推动价格，先于某个行情指标不必意味着能预测独立外部需求。必须把交易自身冲击和后续外部反应分开。
5. **真正的信息剩余与净可交易性。** 即使发现罕见协调，仍需决策时点、真实报价、退出容量、完整样本和成本模型；没有这些就保留研究价值，而不是交易标签。

## 尚未逐文件完成的其他知识

此前项目讨论过开发者追踪、Frogy Telegram/GitBook 资料和新的独立实战项目，但这些来源尚未全部形成**完整的版本锁定原始证据、可复算案例和独立机制对照**。有必要延伸研究，但不应仅凭一次浏览就把它们升级为已掌握的生产知识。

真实部署/数据适配仍未核验：OKX CLI 的文档能力 ≠ 已跑通的具体返回数据，Grok GitHub 文件 ≠ 云电脑自动安装，当前 M2 归一化事件聚合 ≠ 全链实时数据采集。

**高认知完成标准：** 对一个陌生事件，不依赖事后结果也能确定正确的专家组合；专家能够用原始证据互相驳斥；最后输出清楚的事实、未决机制、市场后果、风控、待查签名与可否进入纸面经济实验。没有产生可判断的新证据时，应当承认“本轮知识没有升级”。

**认知指令：** 从旧理论提取可验证命题，由真实机制决定专家分工，以反证驱动知识迭代；不以层级数量替代认知深度。
